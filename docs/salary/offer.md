# Проверка оффера и выход на работу

До согласия сопоставьте оффер с проектом договора и приложениями. Юридическую силу определяет содержание документа. Требования к трудовому договору описаны в [статьях 57 и 67 ТК РФ](../resources/sources.md).

## Чек-лист предложения

| Проверить | Что должно быть понятно до согласия |
| --- | --- |
| Работодатель и оформление | Юридическое лицо, трудовой договор или договор услуг, срок, применимое право |
| Должность | Трудовая функция, команда, руководитель, реальные задачи |
| Grade | Внутренний уровень, критерии, совпадение с обсуждённой ответственностью |
| Зарплата | Фикс gross, период, даты выплат, одинаков ли оклад на испытании и после |
| Бонус | Условия, формула, период, право работодателя не выплатить, пропорция за первый год |
| Sign-on | Выплата, удержания, обязанность возврата, в каких случаях |
| Испытание | Наличие, срок, допустимость, задачи и критерии прохождения |
| Формат работы | Офис/гибрид/удалёнка, место работы, допустимая география, часы, поездки |
| Дежурства и переработки | График, правила привлечения, учёт, компенсация, эскалация |
| Отпуск | Продолжительность, планирование, уже согласованные даты |
| ДМС | Дата начала, программа, доступность в вашем городе |
| Оборудование | Выдача и доставка, компенсация своего, связь, возврат |
| NDA | Какие сведения защищены, срок обязательств, ответственность, доступ к данным |
| Non-compete | Что именно запрещают, когда и по какому праву; не смешивать с NDA |
| Интеллектуальные права | Границы служебных разработок, личные проекты, open source |
| Дата выхода | Конкретная дата, зависимость от проверок и готовности документов |
| Условия до выхода | Завершён ли найм, остались ли проверки/согласования, кто подтверждает финал |

Уточните, как внутренний grade влияет на задачи, оценку и оплату.

## Испытательный срок: актуально на 6 сентября 2026

Обычно испытание длится не более **трёх месяцев**. Шесть месяцев допускаются для отдельных руководящих должностей; для срочного договора на два-шесть месяцев предел — две недели. [Статья 70 ТК РФ](https://www.consultant.ru/document/cons_doc_LAW_34683/cc065f088bd92d312b5fae714377b25f557ac44a/).

С **1 сентября 2026 года** испытание нельзя устанавливать женщинам с детьми до **трёх лет**. Изменение разъяснила [прокуратура Республики Бурятия](https://epp.genproc.gov.ru/ru/proc_03/activity/legal-education/explain/e8550981/). Остальные исключения проверяйте по действующему закону.

Спросите руководителя: «Какие результаты ожидаются через месяц и к концу испытания, кто помогает и когда будет обратная связь?»

## Трудовой договор и услуги — разные условия

Для договора с ИП или самозанятым отдельно проверьте отпуск, больничные, налоги, приёмку, прекращение, ответственность и интеллектуальные права. Сумма по услугам не равна трудовому net.

По трудовому договору основной оплачиваемый отпуск обычно составляет 28 календарных дней. Порядок выдачи оборудования и компенсации своего должен быть в документах. [Статьи 115 и 312.6 ТК РФ](../resources/sources.md).

## NDA и non-compete

NDA защищает конфиденциальность, non-compete ограничивает работу у конкурентов. [Разъяснение прокуратуры](https://epp.genproc.gov.ru/ru/proc_37/activity/legal-education/explain/e356748/) указывает на противоречие трудовому законодательству запрета работать у конкурентов после увольнения; ограничения источника есть в [реестре](../resources/sources.md).

Просите убрать или уточнить спорное условие. При иностранном праве, договоре услуг или существенном ограничении покажите специалисту весь комплект документов.

## Последовательность принятия

1. Получите письменные условия и проекты документов.
2. Сверьте чек-лист, задайте вопросы по расхождениям.
3. Согласуйте итоговый вариант и срок ответа.
4. Подтвердите принятие и дату выхода письменно.
5. Спланируйте завершение текущей работы после оформления перехода.
6. Получите инструкции первого дня: контакты, техника, доступы, место/время встречи.

**Шаблон уточнения:**

> Спасибо за предложение. До подтверждения хочу сверить три пункта: фикс X ₽ gross с первого рабочего дня; удалённый формат из города N с указанной частотой визитов; начало ДМС с даты D. Пришлите, пожалуйста, финальные условия и проект договора. После проверки смогу подтвердить решение до даты T.

Отказ сообщите кратко: «Спасибо за время команды. Я выбрал другой вариант и не смогу принять предложение».
