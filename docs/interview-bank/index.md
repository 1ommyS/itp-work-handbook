!!! tip "Как заниматься"
    Выберите один блок под ближайшую секцию. Отвечайте вслух без конспекта, затем сверяйтесь с ориентиром и записывайте только пробел. Для задач сначала получите рабочее решение, после этого улучшайте сложность и объяснение.

## Режимы подготовки

| До интервью | Режим |
| --- | --- |
| 1–3 дня | Повторите знакомые слабые блоки; не пытайтесь пройти весь список |
| 1–2 недели | Каждый день один блок вопросов и 2–3 задачи одного паттерна |
| Месяц и больше | Чередуйте теорию, код, пробные интервью и интервальные повторы |

Результат занятия — не число просмотренных ответов, а темы, которые вы можете объяснить, и задачи, которые можете повторно решить без подсказки.

## Что сделать прямо сейчас

- [ ] Проведите 30-минутную диагностику без подсказок.
- [ ] Запишите три пробела и назначьте дату повторения.
