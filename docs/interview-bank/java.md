# Java: 240 вопросов для собеседования

Коллекция покрывает путь от Java Core до проектирования production-сервисов. Вопросы разделены на три страницы по 80, чтобы ими было удобно пользоваться как программой подготовки и справочником.

!!! tip "Как отвечать"
    Сначала ответьте без подсказки: определение → механизм → практический пример или риск. Затем прочитайте ориентир. Для middle и senior добавьте компромисс, диагностику или случай из собственного кода.

## Как выбрать глубину

| Уровень | Минимальный маршрут |
| --- | --- |
| Junior | Core целиком; JVM и Spring на уровне базовых механизмов; SQL и тестирование |
| Middle | Все блоки, связанные с вакансией; объяснение компромиссов и типичных сбоев |
| Senior | JVM/concurrency, транзакции, архитектура, диагностика и границы гарантий |

Метки уровня — ориентир редакции, а не стандарт grade. Требования конкретной команды важнее: сначала запросите формат интервью и стек проекта.

## Режим подготовки

1. Выберите 20–30 вопросов под ближайшую секцию.
2. Отвечайте вслух, ограничивая первый ответ двумя минутами.
3. Отмечайте только пробелы; не переписывайте весь ориентир.
4. Закрепляйте сложную тему коротким кодом, тестом или экспериментом.
5. Повторяйте ошибки через несколько дней в перемешанном порядке.
